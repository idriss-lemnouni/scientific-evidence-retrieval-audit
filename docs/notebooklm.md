# Document review in NotebookLM

1. Open NotebookLM in an existing account and add the [SciFact paper](https://aclanthology.org/2020.emnlp-main.609/), the [BEIR paper](https://arxiv.org/abs/2104.08663), and your locally generated metrics report if you can share it.
2. Ask for a matrix of the retrieval question, claim, attached source, passage, and experimental limitation.
3. Follow the citations to the original papers, record any unverified statement, and save your notes with the source URLs and date.
4. Re-run the local benchmark for model scores. Use NotebookLM for reading and comparing methods.

Google documents a Gemini Notebook Enterprise API for licensed users with IAM access. This project implements local retrieval and extractive evidence. The review above uses the web interface. [Enterprise access requirements](https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/api-notebooks)
